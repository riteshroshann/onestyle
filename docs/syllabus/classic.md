# Syllabus coverage: classical NLP

Every row is code in `engine/bespoke/nlp/`, run on Bespoke's own text by `engine/scripts/syllabus.py <topic>`, with a result file in `results/` written by that run and a test in `engine/tests/test_nlp_*.py`. All rows are **study only**: none of them edits the product, so none is used in the product. Where a study shows a gain, the hook is written under the table. Sizes are given next to every number because the gold set is small: 82 requests, 30 dev and 52 test, as split in `engine/scripts/ladder.py`. Choices are made on dev and reported on test.

Corpora: gold requests, synthetic requests (template-generated, so never the only evidence), Myntra catalogue titles (44,417, English, mostly menswear, footwear and accessories; `data/raw/styles.csv`, not in git), the ontology's forms, and the 70 assistant guide chunks. Without the CSV the catalogue-dependent steps fall back to synthetic and guide text or write a "skipped" result.

## Hooks for the web engine

* **Morphological fallback.** After `tagRules` finds no match for a token of 4 or more letters, try the suffix-swap table induced from the ontology (`induce_swaps`), then the sound key already in `web/lib/engine/lexicon.ts` with the same first letter and edit distance 1 (2 from 9 letters). Accept only a unique `(tag, value)`. This grounds "dheelay" and "georget" without new ontology rows and works on typed text as well as speech. Parity fixtures would be needed.
* **Guard.** A learner should only add refusals after the regexes (the hybrid row); at this data size it is not worth shipping.
* **Transcript choice.** A trigram model over ontology and guide text can rank speech alternatives, but the browser does not expose alternatives today.

## Not covered here

Syntax, semantics, POS, NER reporting, dependency parsing, sentiment, translation, question answering, summarisation, seq2seq, BERT probing and GPT belong to the other half. The fine-tuned MiniLM predictions are not in the repository, so the L3 rungs are absent from the significance tests.
